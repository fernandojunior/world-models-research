# World Models Research

Material produzido no projeto de P&D **"Antecipação e Exploração Estratégica de World Models para Inovação em Inteligência Artificial"** (Programa Inova Talentos IEL/CNPq · Instituto Itaú de Ciência, Tecnologia e Inovação · projeto 400988/2026-7 · out/2026 a set/2027).

## Estrutura

| Pasta | Conteúdo |
|---|---|
| [`docs/relatorio-fundamentos/`](docs/relatorio-fundamentos/) | Relatório de pesquisa *World models: fundamentos, fronteira e teses viáveis* — história, matemática, sete escolas, estado da arte, benchmarks, ferramentas open source e problemas abertos |
| [`docs/guias/`](docs/guias/) | Guias de estudo interativos: *World models do zero* (15 seções, glossário, roteiro de leitura) e *Matemática para world models* (19 módulos com simuladores) |
| [`docs/plano-de-trabalho/`](docs/plano-de-trabalho/) | Plano de trabalho do projeto, cronograma visual por macroação e script gerador |
| [`docs/relatorios/`](docs/relatorios/) | Relatórios mensais de atividades |

## Macroações do projeto

1. Planejamento e Fundamentação Conceitual (out–nov/2026)
2. Revisão Bibliográfica Sistemática (dez/2026–fev/2027)
3. Exploração Prática e Experimental, open source (mar–mai/2027)
4. Monitoramento de Tendências e Consolidação (nov/2026–set/2027)
5. Acompanhamento, Disseminação e Prestação de Contas (contínua)
